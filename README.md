# УВМ: Ассемблер и Интерпретатор

Практическая работа №3 по дисциплине «Конфигурационное управление».
Вариант №20.

## Общее описание

Проект представляет собой ассемблер и интерпретатор для учебной
виртуальной машины (УВМ). Ассемблер транслирует текст программы во
внутреннее представление, а затем в бинарный формат (команды по 6 байт).
Интерпретатор выполняет бинарную программу.

## Этапы разработки

- [x] Этап 1. Перевод программы в промежуточное представление
- [ ] Этап 2. Формирование машинного кода
- [ ] Этап 3. Интерпретатор и операции с памятью
- [ ] Этап 4. Реализация АЛУ (бинарная операция «взятие остатка»)
- [ ] Этап 5. Выполнение тестовой задачи

## Структура репозитория

| Путь | Назначение |
|------|-----------|
| `src/isa.py` | Коды операций и размер команды |

| `data/test_program.asm` | Программа с тестовыми командами из спецификации |

## Язык ассемблера

Одна команда на строку: `мнемоника аргумент, аргумент, ...`.
Аргументы — десятичные целые числа. Комментарий начинается с `;`,
пустые строки игнорируются. Регистр мнемоник не важен.

| Команда | Код операции (A) | Аргументы | Действие |
|---------|------------------|-----------|----------|
| `load B, C` | 9 | B — регистр, C — константа | `reg[B] = C` |
| `read B, C` | 29 | B — регистр, C — адрес | `reg[B] = mem[C]` |
| `write B, C` | 25 | B — регистр, C — адрес | `mem[C] = reg[B]` |
| `mod B, C, D` | 22 | B — регистр, C и D — адреса | `mem[C] = mem[D] % reg[B]` |

Пример (`data/test_program.asm`, значения из спецификации):

```text
load 4, 758
read 49, 170
write 5, 119
mod 48, 22, 957
```

## Описание функций и настроек

### Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `--input` | Путь к исходному файлу с текстом программы |
| `--output` | Путь к двоичному файлу-результату (используется с этапа 2) |
| `--test-mode` | Режим тестирования: вывод полей и значений команд |

Код возврата: `0` при успехе, `1` при ошибке разбора или чтения файла.

### Основные функции

- `parser.parse_program(lines)` — список строк в список `Instruction`
  (поля `opcode`, `b`, `c`, `d`).
- `main.main(argv)` — точка входа CLI.

## Сборка и запуск тестов

Требуется Python 3.10+. Сборка не нужна, зависимости только для тестов:

```bash
pip install -r requirements.txt
python3 -m pytest -v        # или: ./run.sh test  (run.bat test)
```

## Примеры использования

```bash
python3 -m src.main --input data/test_program.asm \
    --output program.bin --test-mode
./run.sh --input data/test_program.asm --output program.bin --test-mode
```

Ожидаемый вывод:

```text
Внутреннее представление программы:
  0: A=9, B=4, C=758, D=0
  1: A=29, B=49, C=170, D=0
  2: A=25, B=5, C=119, D=0
  3: A=22, B=48, C=22, D=957

Успешно разобрано команд: 4
```
